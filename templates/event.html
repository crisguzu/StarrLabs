08 TOWER PROTOCOL

How the Tower works

Supercell’s rules define the climb. StarrLabs validates those mechanics because the public battle API does not provide an event-run ID:

  1. Maxed with PowersEvery brawler enters maxed out with event Powers enabled.
  2. Win to climbClear each map to reach the next floor and its reward.
  3. One attempt eachEvery brawler is a one-use pick until the Tower resets.
  4. Perfect at the topReach Floor 5 without a loss to earn the Perfect Run reward.
This is a live StarrLabs sample, not the worldwide event population. Official rules ↗ Supercell FanKit ↗
